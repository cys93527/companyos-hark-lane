# UI-AUDIT-3：设置里填 API Key / 模型服务 / 预算，输入框精简，整体合理性整理（2026-11-11）

来源：用户在 v0.1.5 上回复“需要”（把填 Key 做进设置页，进 v0.1.6），并说：“我截图的都是啥啊，如果没用都给我放在设置界面，你也可以看有些东西的合理性，不合理的你都给整理下”。

基线 ac85f3c（v0.1.5）。不调用真实模型、不新增依赖（DPAPI 仍用随安装包发布并校验的 koffi 3.3.3）。仅 Hark 自查；真实电脑验收与独立审查未进行。完整清单（含每一项的理由）见 `lane/evidence/UI-AUDIT-3/AUDIT.md`（仓库外的 Hark 证据目录），截图见 `lane/evidence/UI-AUDIT-3/screens/`。

## A. 设置 → 模型服务
- 选择“推荐服务”（安装包里的 `provider-profile.json`，价格已填好）或“其他 OpenAI 兼容服务”（https 地址、对话模型 id、每百万 tokens 输入/输出价格）；粘贴 API Key；填写每个目标最多花多少钱；“测试连接”；“保存”；“移除”。一次只有一个服务（运行时只绑定一份 `provider/model.json` 和一份预算批准）。
- **Key 的安全等级与 H17a 相同**：输入框是不受控的密码框，Key 只在输入框的 DOM 里，不进 React 状态、不进本地存储；保存时读出并清空输入框，经新的专用通道 `companyos:provider-settings` 单向交给主进程 `apps/desktop/src/provider-settings.ts`，用 DPAPI（CurrentUser，`CryptProtectData`）加密写入与“首次配置”相同的 `%APPDATA%\CompanyOS\provider\model-api-key.dpapi`。返回给界面的最多是“****末 4 位”；结果、错误、日志（只记操作名和结果码）里都没有 Key。没有用 Electron safeStorage：它的密文格式与现有读取器和开始菜单助手不兼容。
- **预算批准 / 提高、移除、重启都必须由用户在主进程弹出的系统确认框里点“批准并保存 / 移除 / 重启”**；取消则什么都不写。智能体、运行时、工具没有任何路径：只有 `main.ts` 引用该服务，只有应用主窗口的顶层页面能调用该通道，控制面 / 工作流 / 核心服务都不认识它（有测试）。
- 测试连接 = `GET {地址}/models`（列模型，不消耗 tokens，不是模型调用），结果分为：正常（并说明模型 id 是否在列表里）/ Key 被拒（401/403）/ 地址不对（404）/ 服务错误 / 连不上 / 超时。
- 生效方式：**需要重启**（显示“设置已保存，重启 CompanyOS 后生效”和“立即重启”按钮）。不做热更新：模型服务和预算证明在启动组装时绑定一次，在有目标运行时重新组装核心不安全。
- 部署环境变量（`COS_MODEL_*`）声明了模型时仍然优先，设置页显示“由部署环境提供”并拒绝保存。
- 开始菜单“CompanyOS 首次配置”继续可用（同一套写入器和文件）。预算为 0 的提示、服务未启用的横幅都改为指向“设置 → 模型服务”。

## B. 输入框只保留每条消息需要的
保留：输入框、工作空间、模型、发送；“上一次提交尚未确认（重试/放弃）”和预算为 0 的拦截提示（带“设置预算”按钮）。
- 权限（询问权限 ▾）→ 设置 → 新目标默认（单选，本机记住；创建目标时仍由主进程绑定并强制，目标页面显示读回的策略）。
- 工具 → 删除（它只是跳到侧栏的“工具”页面）。
- “高风险操作会停在批准边界，由你决定” → 设置 → 新目标默认（访问权限下的说明）。
- 会话费用 → 删除（目标的“运行”面板已有）。
- 文件交付要求（可选）→ 设置 → 新目标默认（“下一个目标的文件交付要求（可选，高级）”）；填写后输入框只显示“本目标附带文件交付要求：… 修改 / 清除”，发送后自动清空。
- 保存草稿 / 恢复草稿 / “已恢复本地未提交草稿” → 删除；改成静默自动保存（停顿 0.4 秒后保存，清空则删除），打开工作空间时自动填回空输入框。唯一会显示的是：内容像密钥时不保存，并提示一句。
- 设置 / 工具 / 知识库 / 智能体页面不再显示输入框（错误提示仍在每个页面显示）。侧栏底部重复的“工作空间”去掉。

## C. 整体合理性
- 设置顺序：模型服务 · 模型 · 新目标默认 · 工作区 · 关于 · 高级与技术信息（运行与诊断、版本、数据库、IPC 通道等，默认折叠）；去掉“当前目标状态”（不是设置项）。
- 右侧运行面板只在“对话与任务”显示；“目标 · 执行中 · 规划 · …”一行收进提示；预算明细、模型遥测收进“明细 / 技术细节”；重复的“验证”“最近活动”和“未知的数值显示为 --”去掉；任务编号、产物编号收进提示；产出页“缺失”改“待验证”，去掉“移交”。
