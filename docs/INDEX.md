## 验收命令

```powershell
# 依赖安装（必须 Exit Code 0；lockfile 必须与 workspace 一致）
pnpm install --frozen-lockfile

# 唯一的总门：lint → typecheck → boundaries → test → build（必须 Exit Code 0）
pnpm check

# 分步执行（调试用）
pnpm lint ; pnpm typecheck ; node scripts/check-boundaries.mjs ; pnpm test ; pnpm build

# 工具链自检（node --test）
pnpm test:scripts
node scripts/check-workspace.mjs

# 存储与桌面壳
node -e "const {DatabaseSync}=require('node:sqlite');new DatabaseSync(':memory:').exec('select 1')"
pnpm dev            # 需要 Electron 运行时二进制，见 ../PROJECT_HANDOFF.md 的 Known Limitations
```

`pnpm check` 是 Sprint 0 的验收标准（规划书 §六十六 STEP 7）：**Exit Code 必须为 0**。
